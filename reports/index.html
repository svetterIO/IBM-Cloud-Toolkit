Enumeration report

Browse the results of an enumeration run, module by module. Everything is read locally in your browser – no data is uploaded anywhere.

Select the reports/ folder (or drag and drop it onto this page) to load all enumeration runs at once. The latest run is selected automatically. Individual report_YYYYMMDD_HHMMSS folders can be selected directly too. Legacy output_YYYYMMDD_HHMMSS and output folders are also recognised.
